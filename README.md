# LRU Cache UI

An interactive web-based visualization of the Least Recently Used (LRU) Cache.

This project helps understand how LRU cache eviction works by visually showing
most recently used (MRU) and least recently used (LRU) elements.

## 🚀 Live Demo
https://23wh1a0562.github.io/lru-cache-ui/

## ✨ Features
- Set cache capacity
- Add / update key-value pairs
- Access elements (MRU logic)
- Automatic eviction of least recently used item
- Visual linked list representation
- Reset / clear cache
- Clean and responsive UI

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## ▶️ How to Run Locally
1. Clone the repository
2. Open `index.html` in a browser

## 📌 Use Case
Useful for learning data structures and understanding cache eviction strategies.
